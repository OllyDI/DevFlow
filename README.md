# DevFlow

팀의 개발 작업 흐름과 애플리케이션 운영 상태를 관리하는 웹 애플리케이션입니다. 프로젝트와 모듈별 작업을 계획하고, 작업 책임자·참여자·상태·변경 이력을 추적합니다. 요청 로그는 추적 ID로 연결하고, 운영 지표는 Prometheus와 Grafana로 확인합니다.

## 문서

- [프로젝트 계획](PLAN.md): 목표, 범위, 요구사항, 검증 기준, 기술 기준, 단계별 진행 계획
- [상세 설계](DESIGN.md): 화면 구조, 권한, 업무 규칙, 데이터 모델, 애플리케이션 및 관측 구조

## 기술 기준

Java 21, Spring Boot 4.2.0, Gradle 9.x, Spring MVC, Thymeleaf, Spring Data JPA, PostgreSQL, Actuator, Micrometer Prometheus Registry, Prometheus, Grafana를 사용합니다. 상세 호환성 기준은 [PLAN.md](PLAN.md)를 참고하세요.

## 핵심 역할

- **ADMIN:** 서비스 전체 관리자. 프로젝트 매니저를 지정하고 전역 계정과 권한을 관리합니다.
- **프로젝트 매니저:** 관리 프로젝트의 참여 신청·초대, 모듈과 모듈 책임자를 관리합니다.
- **모듈 책임자:** 맡은 모듈과 그 모듈의 작업 배정을 관리합니다.
- **작업 책임자 / 작업 참여자:** 개별 작업을 책임지고 수행하거나 함께 기여합니다.

한 사용자는 여러 프로젝트에 참여할 수 있으며, 프로젝트마다 역할이 다를 수 있습니다.

## 현재 상태

요구사항과 상세 설계를 정리하고 있습니다. 화면 상세 설계와 검토가 끝난 뒤 퍼블리싱 및 구현을 시작합니다.
